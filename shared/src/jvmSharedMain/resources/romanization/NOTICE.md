# Mandarin romanization data

`mandarin.bin` is generated by Metrolist's `scripts/generate_mandarin_table.py`
from Unicode Unihan 17.0.0 `kMandarin` readings and the character and phrase
dictionaries in `com.github.houbb:pinyin:0.4.0`.

- Unihan: https://www.unicode.org/Public/17.0.0/ucd/Unihan.zip
  Licensed under Unicode License V3; see `Unicode-LICENSE.txt`.
- pinyin: https://github.com/houbb/pinyin
  Licensed under Apache License 2.0; see `pinyin-LICENSE.txt`.

Metrolist combines these sources, retains legacy first readings and phrase
segmentation, and encodes them in the compact MPY1 binary format documented
in `docs/desktop-mandarin.md`. The original sources are pinned by SHA-256 in
the generator. The binary is a transformed dataset, not an upstream file.
