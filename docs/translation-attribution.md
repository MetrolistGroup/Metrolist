# Translation attribution

The shared translations in `shared/src/commonMain/composeResources/values-*` include strings originally imported from the
[official Metrolist Android app](https://github.com/MetrolistGroup/Metrolist) at revision
[`6ee482cbe3a076092436a3cb1b53571ffead3097`](https://github.com/MetrolistGroup/Metrolist/tree/6ee482cbe3a076092436a3cb1b53571ffead3097/app/src/main/res).
Metrolist distributes them under its GPL-3.0 license.

The Metrolist and InnerTune localization communities contributed these translations.
Per-language and per-string contributor records are in the
[Metrolist Weblate project](https://hosted.weblate.org/projects/metrolist/) and the
[official resource history](https://github.com/MetrolistGroup/Metrolist/commits/6ee482cbe3a076092436a3cb1b53571ffead3097/app/src/main/res).

Mostafa Al Agamy, Ramazan Sancar, xamax-code, and zhabafrog. Name variants in Git history
are combined in this list. The linked history preserves the original authorship.

Each imported resource file carries a source revision and a link back to this notice.
Do not remove those headers or this attribution when updating or redistributing the
translations.

KMP-specific translations are project contributions, not part of the upstream import. All translations live in
`shared/src/commonMain/composeResources/values-*/strings.xml` and are maintained through the
[Metrolist KMP Weblate project](https://translate.metrolist.cc/projects/metrolist-kmp/metrolist-kmp/).
See [strings.md](strings.md) for the catalog workflow.
