These two original TrueType fonts are test fixtures, dedicated to the public domain under CC0-1.0. Each contains a space and a rectangular A glyph. Their family names and glyph widths differ so consecutive imports can be distinguished.

Regenerate them from the repository root with `python3 androidApp/src/test/resources/font-import-fixtures/generate.py`. The generator uses fontTools; the tests read the checked-in fonts and do not require Python.
